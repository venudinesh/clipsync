## Features

- **Clipboard capture** — background service saves everything you copy.
- **AI cleanup** — summarize, fix, retitle, or convert any clip to markdown, all locally via llama.cpp.
- **Chat** — streaming conversation with local LLM, attachments, history, regenerate.
- **Notes** — markdown editor with tags, pinning, and AI actions (summarize, expand, fix grammar).
- **OCR & Voice** — on-device text recognition (ML Kit) and Whisper transcription.
- **Material 3 or Liquid Glass** — opens on Material; the iOS 26-style glass bar is one toggle away. AMOLED dark mode, 8 soft accents.
- **A tab bar you set up yourself** — nine sliders and three gesture toggles against a live preview, and long press to drag the tabs into any order.
- **One-thumb gestures** — tap a clip to read it and hold for its options, page sideways between clips, swipe any row to pin or delete, pull the feed down to capture, swipe between tabs.

## Install

1. Download the APK, verify the SHA-256.
2. Allow installs from unknown sources.
3. Open **Settings > AI** and download or pick a model.
4. Start the clipboard service from **Settings > System** for background capture.

## Requirements

- Android 7.0+ (API 33 for full Liquid Glass)
- 4 GB+ RAM (6 GB for 3B models, 8 GB+ for 7B)
- 1-5 GB free for model weights
